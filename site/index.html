La consola al detalle

Cada módulo cumple una función forense concreta. Dato primero, decoración nunca.

◉ supervisión

Vigilancia en tiempo real

Un observador revisa de forma continua la carpeta Descargas. Cada archivo nuevo entra en la cola, se clasifica por tipo (código, binario o ignorable) y aparece en la tabla con hora, score y estado textual. Cualquier otro archivo se analiza a mano.

{ } análisis estático

AST línea por línea

El código Python nunca se ejecuta. Se recorre el árbol sintáctico y eval, exec, llamadas al sistema, red y borrado de ficheros se detectan con el número de línea exacto.

▤ multi-formato

Binarios y documentos

Firma mágica, cabeceras PE, JavaScript incrustado en PDF, acciones automáticas y macros VBA en Office. La entropía señala datos ofuscados en un binario de aspecto inocente.

Trazador conductual

El código se ejecuta en un intérprete instrumentado que registra cada llamada peligrosa como evento. Aísla builtins, no el proceso: no es un sandbox. No analices muestras reales aquí. La traza alimenta el score final.

IP, dominios, URLs, correos y hashes que menciona la muestra, catalogados y listos para compartir.

⌘ disfraces y contenedores

Lo que intenta pasar por documento

Detecta factura.pdf.exe (doble extensión), caracteres de sentido invertido en el nombre (RLO) y ejecutables o scripts dentro de un ZIP, revisados sin extraer el paquete. Cada hallazgo indica su confianza: alta, media o baja.

02

Cómo decide

Cuatro fases, de la llegada del archivo al veredicto. Todo en local. Solo sale un hash si activas VirusTotal.

01

Observación

El sistema de archivos notifica en cuanto algo aterriza en Descargas. Nada se queda fuera: ejecutables, documentos, scripts y comprimidos. Para cualquier otra ruta, basta con elegir el archivo.

watchdog · sistema de archivos
02

Clasificación

Extensión, firma mágica y nombre. Un .py va a análisis de código; un .exe o .pdf, a los motores binarios. Las descargas a medias (.crdownload, .part) se ignoran.

dispatcher · firma + extensión
03

Análisis

Reglas YARA, cabeceras PE, macros VBA, JavaScript en PDF, entropía, marcadores de script y trazado AST. Cada hallazgo pesa según su severidad.

6 motores · severidad ponderada
04

Veredicto

Score de 0 a 100, estado (benigno, pendiente o amenaza), hallazgos anotados con MITRE ATT&CK e informe HTML listo para exportar.

score 0–100 · informe autocontenido
03

Seis motores, un veredicto

Los motores que componen el análisis y lo que aporta cada uno.

AST + trazador Recorre el árbol sintáctico y ejecuta en un intérprete instrumentado que aísla builtins, no el proceso: eval, exec, os.system, subprocess, sockets, escrituras y borrados. NÚCLEO
YARA Reglas sobre archivos y memoria: patrones de PowerShell, descarga y ejecución, y contextos de ejecución de código sospechoso. NÚCLEO
PE / pefile Cabeceras ejecutables de Windows, secciones con entropía anómala y tabla de importaciones sospechosas. NÚCLEO
PDF / pypdf JavaScript incrustado, acciones automáticas y lanzamiento de procesos al abrir el documento. NÚCLEO
Office / oletools Macros VBA en documentos y plantillas, con detección de la cadena macro → shell → descarga. NÚCLEO
VirusTotal Consulta por SHA-256 contra decenas de antivirus. Activación opcional con clave API gratuita; el resto funciona en local. OPCIONAL
